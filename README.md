**GitLab ↔ GitHub Repository Mirroring**

Overview:
This repository demonstrates how to mirror a GitLab repository to GitHub automatically.  
It’s a small hands-on project created to understand how repository mirroring works in real-time.

Whenever new commits are pushed to GitLab → they automatically sync to GitHub through mirroring

Key Concepts:
- Repository mirroring (Push Mirror)
- GitLab → GitHub synchronization
